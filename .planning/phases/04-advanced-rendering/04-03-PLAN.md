**Step 1: Create src/rendering/ForceGraph.tsx**

```typescript
export function ForceGraph(props: ForceGraphProps): JSX.Element
```

Props destructuring with defaults: `width=600, height=400, nodeRadius=8, labelSize=10, linkOpacity=0.4, linkCurvature=0, charge=-30, linkDistance=30, centerStrength=1, collisionRadius=0, alphaDecay=0.0228, alphaMin=0.001, canvasThreshold=500`.

**Determine rendering mode:** `const useCanvas = nodes.length > canvasThreshold;`

**Deep-clone input data on mount:** Use `structuredClone(nodes)` and `structuredClone(links)` stored in refs. This prevents d3-force from mutating caller's data. Update clones when `nodes` or `links` prop changes (track via JSON.stringify of ids or a version counter).

**D3-Force simulation setup (useEffect, deps: [nodes, links]):**
1. Clone nodes/links into `nodesRef.current` and `linksRef.current`
2. Create simulation:
```typescript
const sim = forceSimulation<GraphNode>(nodesRef.current)
  .force('charge', forceManyBody<GraphNode>().strength(charge))
  .force('link', forceLink<GraphNode, GraphLink>(linksRef.current).id(d => d.id).distance(linkDistance))
  .force('center', forceCenter(width / 2, height / 2).strength(centerStrength))
  .force('collide', collisionRadius > 0 ? forceCollide<GraphNode>(collisionRadius) : null)
  .alphaDecay(alphaDecay)
  .alphaMin(alphaMin);
```
3. Batch tick updates to rAF to avoid re-render thrashing:
```typescript
let frameId = 0;
sim.on('tick', () => {
  cancelAnimationFrame(frameId);
  frameId = requestAnimationFrame(() => setTick(t => t + 1));
});
sim.on('end', () => onStabilize?.());
```
4. Store sim in `simulationRef.current`
5. Cleanup: `sim.stop(); cancelAnimationFrame(frameId);`

**Force parameter updates (useEffect, deps: [charge, linkDistance, centerStrength, collisionRadius]):**
Update forces imperatively on existing simulation without recreating:
```typescript
simulationRef.current?.force('charge', forceManyBody<GraphNode>().strength(charge));
// ... etc
simulationRef.current?.alpha(0.3).restart();
```

**State:**
- `tick: number` (useState, incremented by rAF-batched simulation tick, triggers re-render)
- `hoveredNode: GraphNode | null` (useState, for highlight effect)
- `dragNode: useRef<GraphNode | null>(null)` (ref, not state -- no re-render during drag move)

**Helper functions:**
- `getNodeRadius(node)`: returns `typeof nodeRadius === 'function' ? nodeRadius(node) : nodeRadius`
- `getNodeColor(node)`: returns `nodeColor ? nodeColor(node) : colorRamps.category10((node.group ?? 0) / 10)`
- `getLinkWidth(link)`: returns `typeof linkWidth === 'function' ? linkWidth(link) : (linkWidth ?? 1)`
- `getLinkColor(link)`: returns `typeof linkColor === 'function' ? linkColor(link) : (linkColor ?? 'var(--sim-border, #27272a)')`
- `isConnected(nodeA, nodeB)`: checks if a link exists between two nodes (precompute adjacency set on data change)

**Adjacency precomputation:** On nodes/links change, build a `Set<string>` of `${sourceId}-${targetId}` and `${targetId}-${sourceId}` pairs. Store in ref. `isConnected` does set.has lookup.

**SVG Mode rendering (when !useCanvas):**

Container div with position:relative. SVG element with `width`, `height`, viewBox `0 0 ${width} ${height}`.

Links rendered as `<line>` elements (or `<path>` with quadratic bezier if linkCurvature > 0):
- For curved links: compute control point perpendicular to link midpoint, offset by curvature * link_length. Use `<path d="M x1,y1 Q cx,cy x2,y2">`.
- Opacity: if hoveredNode exists and link is not connected to hoveredNode, opacity = 0.2 * linkOpacity; else linkOpacity.
- Width: if hoveredNode and connected, width * 1.5; else normal width.

Nodes rendered as `<circle>` elements:
- cx={node.x}, cy={node.y}, r={getNodeRadius(node)}
- fill={getNodeColor(node)}
- stroke="var(--sim-border, #27272a)", strokeWidth={1.5}
- If hovered: transform=`scale(1.2)` via transform-origin center, brighter fill
- If hoveredNode exists and this node is NOT hoveredNode and NOT connected to hoveredNode: opacity=0.2
- Pointer events: onPointerDown -> start drag, onPointerEnter -> set hoveredNode + call onNodeHover, onPointerLeave -> clear hoveredNode + call onNodeHover(null), onClick -> call onNodeClick

Labels rendered as `<text>` elements below each node:
- Only if nodeLabel prop is provided
- x={node.x}, y={node.y + getNodeRadius(node) + labelSize + 2}
- textAnchor="middle", fontSize={labelSize}, fill="var(--sim-text-muted, #a1a1aa)"
- Same opacity dimming as nodes when hovering

**Node drag implementation (SVG mode):**
- onPointerDown on circle: `e.preventDefault(); (e.target as Element).setPointerCapture(e.pointerId); dragNode.current = node; node.fx = node.x; node.fy = node.y; simulationRef.current?.alphaTarget(0.3).restart();`
- Attach onPointerMove and onPointerUp to the SVG element (or via ref):
  - onPointerMove: if dragNode.current, compute SVG coordinates from clientX/clientY via `svgRef.current.getBoundingClientRect()`, set `dragNode.current.fx = svgX; dragNode.current.fy = svgY;`
  - onPointerUp: if dragNode.current, `simulationRef.current?.alphaTarget(0);` If `e.shiftKey`, keep fx/fy (pinned). Else set `node.fx = null; node.fy = null;`. If node is already pinned (from previous shift+release) and user clicks without shift and without dragging (no pointer move between down and up), unpin: `node.fx = null; node.fy = null;`.
  - Set cursor to 'grabbing' during drag via inline style.

**Canvas2D Mode rendering (when useCanvas):**
Render a `<canvas>` element instead of SVG. Use rAF loop:
1. Clear canvas
2. Draw links: `ctx.beginPath(); ctx.moveTo(sx, sy); ctx.lineTo(tx, ty); ctx.strokeStyle = linkColor; ctx.lineWidth = linkWidth; ctx.globalAlpha = linkOpacity; ctx.stroke();`
3. Draw nodes: `ctx.beginPath(); ctx.arc(node.x, node.y, radius, 0, Math.PI*2); ctx.fillStyle = getNodeColor(node); ctx.fill(); ctx.strokeStyle = 'var(--sim-border)' resolved via getComputedStyle; ctx.lineWidth = 1.5; ctx.stroke();`
4. Hover highlighting: same opacity dimming logic, applied to globalAlpha.
5. Labels: only for hovered node (hover-only in Canvas2D per user decision). Draw text below hovered node.
6. Hit testing: use `simulationRef.current?.find(x, y, maxRadius)` for hover and click detection. maxRadius = Math.max of all node radii + 4px tolerance.
7. Pointer events on canvas: onPointerMove -> find node under cursor for hover, onPointerDown -> find node for drag start, onPointerUp -> drag end with same shift logic.
8. DPR: scale canvas context by devicePixelRatio, set canvas.width/height to CSS size * dpr.

**Tooltip rendering:**
If `tooltipContent` and `hoveredNode`: render a div absolutely positioned at the hovered node's screen position (node.x + nodeRadius + 8, node.y). The div has `pointer-events: none`, background `var(--sim-surface, #18181b)`, border `1px solid var(--sim-border, #27272a)`, border-radius `var(--sim-radius, 6px)`, padding `8px 12px`, color `var(--sim-text, #fafafa)`, z-index 10. Contains the ReactNode returned by `tooltipContent(hoveredNode)`. Clamp position to stay within container bounds.
