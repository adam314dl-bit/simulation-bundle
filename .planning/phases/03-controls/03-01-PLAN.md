Create `src/controls/ParameterPanel.tsx` with the following structure:

**Props interface:**
```typescript
export interface ParameterPanelProps {
  schema: ParameterSchema;
  columns?: 1 | 2;
  compact?: boolean;
  className?: string;
}
```

**Component structure:**
- Top-level: `<div ref={containerRef} className={clsx('sim-panel', compact && 'sim-panel-compact', className)}>`
- Use ResizeObserver on containerRef to set autoColumns state (1 below 320px, 2 above). If `columns` prop is provided, skip ResizeObserver and use prop value. If `compact` is true, force 1 column.
- CSS grid: `style={{ display: 'grid', gridTemplateColumns: \`repeat(\${cols}, 1fr)\`, gap: compact ? '8px' : '16px' }}`
- Iterate `Object.entries(schema)` and switch on `def.type` to render the correct inline sub-component.

**Range control:**
- `<label>` with `def.label ?? key` text
- `<input type="range" min={def.min} max={def.max} step={def.step ?? 1} value={value as number}>` with `onInput` handler calling `setParameter(key, Number(e.target.value))`
- Thin 4px track via inline styles: `appearance: none`, `height: 4px`, `background: linear-gradient(to right, var(--sim-accent) ${pct}%, var(--sim-border) ${pct}%)`, `borderRadius: 2px`
- Numeric value `<span>` to the right of the slider showing current value
- Thumb styled via CSS-in-JS or a `<style>` block: `width: 14px`, `height: 14px`, `borderRadius: 50%`, `background: var(--sim-accent)`, `border: none`, `cursor: pointer`

**Toggle control:**
- `<button role="switch" aria-checked={value}>` pill-shaped: `width: 40px`, `height: 22px`, `borderRadius: 11px`, `background: value ? var(--sim-accent) : var(--sim-border)`, `transition: background 0.15s`
- Inner circle (thumb): absolute positioned `<span>`, 16px circle, translates left/right based on value
- onClick calls `setParameter(key, !value)`

**Select control:**
- `<select>` with `background: var(--sim-surface)`, `border: 1px solid var(--sim-border)`, `color: var(--sim-text)`, `borderRadius: var(--sim-radius-sm)`, `padding: 4px 8px`
- `onChange` calls `setParameter(key, e.target.value)`
- Map `def.options` to `<option>` elements

**Color control:**
- `<div>` row: small swatch (20x20 div with `background: value`, `borderRadius: var(--sim-radius-sm)`, `border: 1px solid var(--sim-border)`) + `<input type="color" value={value}>` with `onInput` handler

**Vec2 control:**
- Two stacked rows, each with label ("X" / "Y") and a range input
- Each range: `min={def.min} max={def.max}` with value from `(value as [number, number])[0]` and `[1]`
- onChange for X: `setParameter(key, [newX, (value as [number, number])[1]])`
- onChange for Y: `setParameter(key, [(value as [number, number])[0], newY])`

**Group control (collapsible):**
- `<div>` with a `<button>` header: chevron character (▸ collapsed / ▾ expanded) + `def.label`
- `useState(true)` for expanded state (start expanded per locked decision)
- Content `<div ref={contentRef}>` with `overflow: hidden`, `transition: height 0.2s ease`. Measure height via contentRef.scrollHeight. Set `height: expanded ? measuredHeight : 0`.
- Recursively render `Object.entries(def.children)` using the same switch logic

**Reset All button:**
- At bottom-right: `<button className="sim-reset-btn">Reset All</button>` with `onClick={() => resetParameters()}`
- Styled as ghost/text button: `background: transparent`, `color: var(--sim-text-muted)`, `border: none`, `cursor: pointer`, `fontSize: 12px`
- Hover: `color: var(--sim-text)`

**Compact mode:**
- When `compact={true}`: labels render inline (flexbox row) with controls instead of stacked (flexbox column), gap is 8px, forced single column
- Add `data-compact` attribute or className `sim-panel-compact` for test verification

**All styling uses inline styles + CSS custom properties (--sim-*).** Do NOT create a separate CSS file. Use `clsx` for className composition.

**Hook usage:**
```typescript
const parameters = useParameters();
const setParameter = useSimulation(s => s.setParameter);
const resetParameters = useSimulation(s => s.resetParameters);
```
