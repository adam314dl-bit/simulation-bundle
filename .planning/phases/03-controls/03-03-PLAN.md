**State:**
```typescript
const [activeIndex, setActiveIndex] = useState<number | null>(null);
const setParameter = useSimulation(s => s.setParameter);
```

**Apply preset helper:**
```typescript
function applyPreset(preset: Preset, index: number) {
  for (const [key, value] of Object.entries(preset.config)) {
    setParameter(key, value);
  }
  setActiveIndex(index);
}
```

**Pills variant (default):**
- Container: `display: flex`, `flexWrap: wrap`, `gap: 8px`

  - `cursor: pointer`, `fontSize: 13px`, `fontFamily: var(--sim-font-family)`, `transition: background 0.15s`
- onClick: `applyPreset(presets[i], i)`
