**Speed badge cycling logic:**
```typescript
function cycleSpeed(current: SpeedPreset, backward: boolean): SpeedPreset {
  const idx = SPEED_PRESETS.indexOf(current);
  const next = backward
    ? (idx - 1 + SPEED_PRESETS.length) % SPEED_PRESETS.length
    : (idx + 1) % SPEED_PRESETS.length;
  return SPEED_PRESETS[next];
}
```

**Scrubber implementation:**
- Track div: `position: relative`, `height: 6px`, `background: var(--sim-border)`, `borderRadius: 3px`, `cursor: pointer`
- Filled portion: absolute `<div>` with `width: ${(tick / Math.max(historySize - 1, 1)) * 100}%`, `background: var(--sim-accent)`, `height: 100%`, `borderRadius: 3px`
- Thumb: absolute `<div>` at filled boundary, `width: 14px`, `height: 14px`, `borderRadius: 50%`, `background: var(--sim-accent)`, `border: 2px solid var(--sim-surface)`, `transform: translate(-50%, -50%)`, `top: 50%`
- PointerEvents: `onPointerDown` on track → `setPointerCapture`, compute tick from `e.clientX` relative to track bounds → `seekToTick`. `onPointerMove` while dragging → seek. `onPointerUp` → release.
- Seek calculation: `const rect = trackRef.current.getBoundingClientRect(); const ratio = Math.max(0, Math.min(1, (e.clientX - rect.left) / rect.width)); const targetTick = Math.round(ratio * (historySize - 1)); seekToTick(targetTick);`

**Keyframe markers:**
- Below the scrubber track, `position: relative`, `height: 8px`
- For each event in `useEvents()`, compute x position: `(event.tick / Math.max(historySize - 1, 1)) * 100`
- Render `<div>` dots: `position: absolute`, `width: 4px`, `height: 4px`, `borderRadius: 50%`, `bottom: 0`
- Color by severity: `info` → `var(--sim-accent)`, `warning` → `var(--sim-warning)`, `critical` → `var(--sim-danger)`
- `title` attribute with event message for tooltip
- `onClick` on marker calls `seekToTick(event.tick)`
- Clustering: if two events map to the same pixel (Math.round of position), show only one dot with the highest severity. Use a Map keyed by rounded pixel position.

**FPS counter:**
- Use `useRef` for frame times array (rolling 30-frame window)
- Subscribe to store changes via `useSimulation(s => s.subscribe)` or `useEffect` + `store.subscribe`
- On each tick: `performance.now()` pushed to frame times, prune older than 30 entries, compute `fps = (count - 1) / elapsed * 1000`
- Display via `useRef` + direct DOM update (textContent) to avoid re-renders, OR use throttled setState (update every 500ms)
- Display: `<span style={{ color: 'var(--sim-text-muted)', fontSize: '11px', fontFamily: 'var(--sim-font-mono)' }}>FPS: {fps}</span>`

**Keyboard shortcuts (useEffect on window):**
```typescript
useEffect(() => {
  if (enableShortcuts === false) return;
  const handler = (e: KeyboardEvent) => {
    const tag = (e.target as HTMLElement)?.tagName;
    if (tag === 'INPUT' || tag === 'TEXTAREA' || tag === 'SELECT') return;
    switch (e.key) {
      case ' ':
        e.preventDefault();
        toggle();
        break;
      case 'ArrowRight':
        e.preventDefault();
        if (e.shiftKey) seekToTick(Math.min(tick + 10, historySize - 1));
        else step();
        break;
      case 'ArrowLeft':
        e.preventDefault();
        if (e.shiftKey) seekToTick(Math.max(tick - 10, 0));
        else stepBack();
        break;
    }
  };
  window.addEventListener('keydown', handler);
  return () => window.removeEventListener('keydown', handler);
}, [enableShortcuts, toggle, step, stepBack, seekToTick, tick, historySize]);
```
