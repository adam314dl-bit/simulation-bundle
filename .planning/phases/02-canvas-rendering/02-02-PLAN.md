Create `src/rendering/SimCanvas.tsx` — a React component that:

**Canvas setup:**
- Renders a `<canvas>` element via ref
- Accepts `width` (default 800), `height` (default 600), `onDraw`, `className` props matching `SimCanvasProps`
- On mount + resize: set `canvas.width = width * dpr`, `canvas.height = height * dpr`, `canvas.style.width = '${width}px'`, `canvas.style.height = '${height}px'`
- Get context with `getContext('2d', { alpha: false })` for performance
- Set `touch-action: none` CSS on canvas to prevent browser gesture interference

**Viewport management:**
- Create `Viewport` instance in a `useRef` (NOT state — avoids re-renders)
- Viewport dpr set to `window.devicePixelRatio || 1`

**rAF animation loop:**
- `useEffect` starts `requestAnimationFrame` loop
- Each frame: call `viewport.applyMomentum()`, then `ctx.save()`, `ctx.setTransform(dpr * scale, 0, 0, dpr * scale, dpr * tx, dpr * ty)`, call `onDraw(ctx, viewport)`, `ctx.restore()`
- Cleanup: `cancelAnimationFrame` in useEffect return
- Use a `mountedRef` boolean to prevent post-unmount updates

**Wheel zoom (cursor-centered):**
- Attach wheel listener via `addEventListener('wheel', handler, { passive: false })` in a useEffect (NOT React's onWheel — React uses passive listeners that prevent `preventDefault`)
- `e.preventDefault()` to stop page scroll
- Get cursor position relative to canvas: `e.clientX - rect.left`, `e.clientY - rect.top`
- Call `viewport.zoomAt(cx, cy, e.deltaY)`

**Click-drag pan:**
- Use PointerEvents (not MouseEvent — unified mouse/touch/pen)
- `onPointerDown`: record start position, set `pointerCapture`, track `isPanning = true`
- `onPointerMove`: if panning, compute `dx = e.clientX - lastX`, `dy = e.clientY - lastY`, call `viewport.pan(dx, dy)`, update lastX/lastY, track velocity for momentum
- `onPointerUp`: release capture, set `isPanning = false`, call `viewport.startMomentum(vx, vy)` with averaged velocity from last 3 frames
- Store pan state in refs (isPanningRef, lastPosRef, velocityRef)

**Touch pinch-zoom:**
- Track active pointers via a `Map<number, {x, y}>`
- On pointerdown, add to map. On pointerup/cancel, remove.
- When 2 pointers active during pointermove: compute distance between them, compute midpoint. Scale = newDist / prevDist. Apply `viewport.zoomAt(midX, midY, ...)` with computed scale ratio.
- Store previous distance in ref to compute delta.

**Component structure:**
