**Container structure:**
```tsx
export const LayerStack: React.FC<LayerStackProps> = ({ children, selectionMode = 'none', onSelect, className }) => {
  const containerRef = useRef<HTMLDivElement>(null);
  const svgRef = useRef<SVGSVGElement>(null);
  // Selection state refs (imperative for performance during drag)
  const isDraggingRef = useRef(false);
  const startPosRef = useRef<{ x: number; y: number }>({ x: 0, y: 0 });
  const lassoPointsRef = useRef<[number, number][]>([]);
  const selectionElRef = useRef<SVGElement | null>(null);

  return (
    <div
      ref={containerRef}
      className={className}
      style={{ position: 'relative', overflow: 'hidden' }}
    >
      {children}
      {selectionMode !== 'none' && (
        <svg
          ref={svgRef}
          style={{
            position: 'absolute',
            top: 0,
            left: 0,
            width: '100%',
            height: '100%',
            pointerEvents: 'all',
            zIndex: 9999,
          }}
          onPointerDown={handlePointerDown}
          onPointerMove={handlePointerMove}
          onPointerUp={handlePointerUp}
        />
      )}
    </div>
  );
};
```

**Children rendering:**
- Children are rendered inside the `<div>` container
- Each child is expected to have its own sizing (SimCanvas handles its own width/height)
- The container uses `position: relative` so children with `position: absolute` stack correctly
- Z-ordering is natural DOM order: first child = bottom, last child = top
- SVG overlay is always rendered last (topmost) via the `zIndex: 9999` style

**Rect selection mode:**
- `onPointerDown`: record start position (relative to container), create SVG `<rect>` element imperatively via `document.createElementNS('http://www.w3.org/2000/svg', 'rect')`, set initial attributes, append to SVG, set pointer capture
- Rect styling: `stroke` = accent color (read `getComputedStyle(containerRef.current).getPropertyValue('--sim-accent')` or fallback `#6366f1`), `stroke-dasharray` = '6 3' (dashed), `fill` = accent color with 50% opacity, `stroke-width` = 1.5
- `onPointerMove`: update rect x/y/width/height imperatively via `setAttribute` (NOT React state — performance during drag). Compute: `x = Math.min(startX, curX)`, `y = Math.min(startY, curY)`, `width = Math.abs(curX - startX)`, `height = Math.abs(curY - startY)`
- `onPointerUp`: release capture, remove SVG rect element, fire `onSelect` with `{ type: 'rect', bounds: { x, y, width, height } }` in world coordinates. Remove the rect element from SVG.

**Lasso selection mode:**
- `onPointerDown`: record start position, initialize `lassoPointsRef` with start point, create SVG `<path>` element imperatively, append to SVG
- Path styling: same as rect (accent dashed stroke, 50% fill)
- `onPointerMove`: add current position to `lassoPointsRef`, update path `d` attribute: `M x0,y0 L x1,y1 L x2,y2 ...` (no close yet during drag)
- `onPointerUp`: close the path (add `Z` to d attribute), fire `onSelect` with `{ type: 'lasso', vertices: lassoPointsRef.current }` in world coordinates, remove path element

**Coordinate handling:**
- All selection coordinates are relative to the container's bounding rect
- `const rect = containerRef.current.getBoundingClientRect()`, `x = e.clientX - rect.left`, `y = e.clientY - rect.top`
- The onSelect callback receives these container-relative coordinates (consumers map to world coords via their viewport)

**Cleanup:**
- On unmount or selectionMode change, remove any lingering SVG selection elements
