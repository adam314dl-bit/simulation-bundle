**src/demos/ecosystem/simulation.ts:**

Export `EcosystemEntities` interface:
```typescript
export interface EcosystemEntities {
  grid: Uint8Array;        // 0=empty, 1=grass, 2=rabbit, 3=fox
  width: number;
  height: number;
  stats: { grass: number; rabbits: number; foxes: number; tick: number };
}
```

Export `ecosystemSchema: ParameterSchema` with 8 parameters:
| Key | Type | Min | Max | Step | Default | Label |
|-----|------|-----|-----|------|---------|-------|
| grassGrowth | range | 0 | 0.1 | 0.01 | 0.03 | Grass Growth |
| rabbitBreed | range | 0 | 0.2 | 0.01 | 0.05 | Rabbit Breed Rate |
| rabbitStarve | range | 0 | 0.1 | 0.01 | 0.02 | Rabbit Starvation |
| foxHunt | range | 0 | 0.15 | 0.01 | 0.04 | Fox Hunt Rate |
| foxDeath | range | 0 | 0.2 | 0.01 | 0.08 | Fox Death Rate |
| foxBreed | range | 0 | 0.1 | 0.01 | 0.03 | Fox Breed Rate |
| initialDensity | range | 0.1 | 0.9 | 0.05 | 0.5 | Initial Density |
| gridSize | select | options: ["50","100","150","200"] | default: "100" | Grid Size |

Export `createEcosystem(width: number, height: number, density: number): EcosystemEntities` — initializes grid with random placement: ~50% of filled cells as grass, ~35% rabbits, ~15% foxes.

Export `ecosystemTick: TickFn<EcosystemEntities>` implementing stochastic cellular automaton:
- Iterate all cells in random-shuffled order (Fisher-Yates on index array, reuse each tick)
- Empty cell: grows grass with probability `grassGrowth`
- Grass cell: if adjacent rabbit, rabbit moves in with probability `rabbitBreed`; stays grass otherwise
- Rabbit cell: if adjacent fox, fox eats rabbit (cell becomes fox) with probability `foxHunt`; rabbit starves with probability `rabbitStarve`; otherwise rabbit stays
- Fox cell: fox dies with probability `foxDeath`; if fox just ate (foxBreed event), fox reproduces to adjacent empty cell with probability `foxBreed`
- Count grass/rabbits/foxes at end for stats
- Return NEW EcosystemEntities (new Uint8Array, new stats object) — never mutate input

Helper: `getNeighbors(index, width, height): number[]` returns up to 4 cardinal neighbor indices (not diagonal).
