**src/demos/network/simulation.ts:**

Export `NetworkEntities` interface:
```typescript
export interface NetworkEntities {
  nodes: GraphNode[];      // Each node has opinion: number (0-1), group: number
  links: GraphLink[];
  stats: { avgOpinion: number; clusters: number; variance: number; tick: number };
}
```

Export `generateScaleFreeGraph(n: number, m: number): { nodes: GraphNode[]; links: GraphLink[] }`:
- Barabasi-Albert preferential attachment algorithm (~30 lines)
- Seed: complete graph of m+1 nodes
- Each new node connects to m existing nodes with probability proportional to degree
- Each node gets `opinion: Math.random()` (uniform 0-1) and `group: 0`
- Node IDs as strings: `"0"`, `"1"`, etc.
- Link source/target as string IDs

Export `networkSchema: ParameterSchema` with 8 parameters:
| Key | Type | Range/Options | Default | Label |
|-----|------|---------------|---------|-------|
| nodeCount | select | ["30","50","100","200"] | "50" | Node Count |
| connectionsPerNode | range | 1-5, step 1 | 3 | Connections/Node |
| confidenceThreshold | range | 0.05-1.0, step 0.05 | 0.3 | Confidence Threshold |
| convergenceRate | range | 0.01-0.5, step 0.01 | 0.1 | Convergence Rate |
| interactionsPerTick | range | 1-20, step 1 | 5 | Interactions/Tick |
| mediaNode | toggle | — | false | Media Node |
| mediaBias | range | 0-1, step 0.05 | 0.8 | Media Bias |
| mediaReach | range | 0.1-1.0, step 0.05 | 0.5 | Media Reach |

Export `createNetwork(nodeCount: number, m: number, mediaEnabled: boolean, mediaBias: number, mediaReach: number): NetworkEntities`:
- Generate graph via `generateScaleFreeGraph(nodeCount, m)`
- If mediaEnabled: add a special node with id "media", opinion=mediaBias, group=99, radius=12. Connect it to `Math.floor(nodeCount * mediaReach)` random nodes.
- Compute initial stats

Export `opinionTick: TickFn<NetworkEntities>`:
1. Read params: confidenceThreshold, convergenceRate, interactionsPerTick, mediaNode, mediaBias
2. Deep copy nodes: `nodes.map(n => ({ ...n }))`
3. For `interactionsPerTick` random interactions:
   a. Pick random link
   b. Get source and target nodes (resolve string IDs to node objects)
   c. If `|opinion_i - opinion_j| < confidenceThreshold`: both move toward each other by `convergenceRate * diff`
   d. If either node is "media" node, its opinion stays fixed at mediaBias
4. Assign groups by opinion clustering: group = Math.floor(opinion * 5) (5 bins: 0-0.2, 0.2-0.4, etc.)
5. Color nodes by opinion: interpolate from blue (opinion=0) to red (opinion=1) using `rgb(${Math.round(o*255)}, 0, ${Math.round((1-o)*255)})`
6. Compute stats:
   - avgOpinion: mean of all opinions
   - variance: standard deviation of opinions
   - clusters: count of distinct groups with >= 3 members
7. Return new NetworkEntities (new nodes array, same links, new stats)
