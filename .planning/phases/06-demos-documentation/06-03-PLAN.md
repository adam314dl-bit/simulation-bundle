**src/demos/particles/simulation.ts:**

Export `ParticleEntities` interface:
```typescript
export interface Attractor { x: number; y: number; strength: number; }
export interface ParticleEntities {
  particles: Float32Array;  // interleaved [x, y, vx, vy] stride 4
  count: number;
  attractors: Attractor[];
  stats: { avgSpeed: number; avgDistance: number; tick: number };
}
```

Export `particleSchema: ParameterSchema` with 8 parameters:
| Key | Type | Range/Options | Default | Label |
|-----|------|---------------|---------|-------|
| gravity | range | 0-5, step 0.1 | 1.0 | Gravity |
| timeStep | range | 0.001-0.05, step 0.001 | 0.016 | Time Step |
| damping | range | 0-0.1, step 0.001 | 0.001 | Damping |
| particleCount | select | ["500","1000","2000","5000"] | "1000" | Particle Count |
| boidsEnabled | toggle | — | false | Boids Flocking |
| separation | range | 0-5, step 0.1 | 1.5 | Separation |
| alignment | range | 0-5, step 0.1 | 1.0 | Alignment |
| cohesion | range | 0-5, step 0.1 | 1.0 | Cohesion |

Export `createParticles(count: number, pattern: 'random' | 'ring' | 'burst'): ParticleEntities`:
- `random`: uniform random positions in [-1,1] x [-1,1], zero velocity
- `ring`: particles in a circle with tangential velocity (for galaxy spiral)
- `burst`: particles at center with radial outward velocity (for fireworks)

Export `particleTick: TickFn<ParticleEntities>`:
1. Read params: gravity, timeStep (dt), damping, boidsEnabled, separation, alignment, cohesion
2. Create new Float32Array(particles.length)
3. For each particle i (stride 4: x, y, vx, vy):
   a. Compute gravitational acceleration from all attractors: `a = G * strength * (attractor - pos) / |dist|^2` (softened with epsilon=0.01 to prevent singularity)
   b. If boidsEnabled: for neighbors within radius 0.1, compute separation (repel), alignment (match velocity), cohesion (move toward center) forces
   c. Apply damping: `v *= (1 - damping)`
   d. Euler integration: `v += a * dt`, `pos += v * dt`
   e. Wrap positions to [-2, 2] bounds (toroidal for galaxy, clamp for others)
4. Compute stats: average speed (|v| across all particles), average distance from origin
5. Return new ParticleEntities with new Float32Array and new stats

N-body between particles: for count <= 2000, compute pairwise gravity O(n^2). For count > 2000, skip inter-particle gravity (only attractors). This keeps tick under 2ms.
