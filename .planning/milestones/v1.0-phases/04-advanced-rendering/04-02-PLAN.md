Create `src/rendering/ParticleRenderer.tsx` implementing the full particle renderer. Structure:

**GLSL Shaders (as string constants at top of file):**

Vertex shader (`VERT_SRC`):
```glsl
#version 300 es
precision highp float;
in vec2 a_position;
in vec2 a_velocity;
uniform mat3 u_transform;
uniform float u_pointSize;
out float v_colorT;
void main() {
  vec3 pos = u_transform * vec3(a_position, 1.0);
  gl_Position = vec4(pos.xy, 0.0, 1.0);
  gl_PointSize = u_pointSize;
  float speed = length(a_velocity);
  v_colorT = clamp(speed, 0.0, 1.0);
}
```

Fragment shader (`FRAG_SRC`):
```glsl
#version 300 es
precision highp float;
in float v_colorT;
uniform sampler2D u_colorRamp;
out vec4 fragColor;
void main() {
  vec2 center = gl_PointCoord - 0.5;
  float dist = length(center) * 2.0;
  if (dist > 1.0) discard;
  float alpha = exp(-dist * dist * 4.0);
  vec4 color = texture(u_colorRamp, vec2(v_colorT, 0.5));
  fragColor = vec4(color.rgb, alpha);
}
```

Fade quad shaders (`FADE_VERT_SRC`, `FADE_FRAG_SRC`):
- Simple fullscreen triangle vertex shader (positions [-1,-1], [3,-1], [-1,3])
- Fragment: `uniform vec4 u_fadeColor; out vec4 fragColor; void main() { fragColor = u_fadeColor; }`

**Component Structure:**

```typescript
export function ParticleRenderer(props: ParticleRendererProps): JSX.Element
```

Props destructuring with defaults: `width=600, height=400, colorRamp='viridis', colorMap='velocity', pointSize=4, trails=false, trailAlpha=0.05, blendMode='additive', renderer='auto'`.

**Refs:**
- `canvasRef: useRef<HTMLCanvasElement>(null)`
- `glRef: useRef<WebGL2RenderingContext | null>(null)`
- `programRef, fadeProgRef, vaoRef, bufferRef, textureRef, fadeVaoRef: useRef<WebGL*>(null)`
- `rafRef: useRef<number>(0)`
- `contextLostRef: useRef<boolean>(false)`
- `modeRef: useRef<'webgl2' | 'canvas2d'>('webgl2')` — tracks active rendering mode
- `frameCountRef: useRef<number>(0)` — for periodic full clear (every 1000 frames to fix trail alpha drift)

**Mount useEffect (primary, deps: []):**
1. Get canvas, try `canvas.getContext('webgl2')` if `renderer !== 'canvas2d'`
2. If gl is null or renderer is 'canvas2d': set `modeRef.current = 'canvas2d'`, call `onFallback?.('WebGL2 not available')` if originally requested webgl2, `console.warn('sim-kit: WebGL2 unavailable, using Canvas2D fallback')`, and return (Canvas2D rAF loop handled separately)
3. If gl obtained: store in glRef, query `gl.getParameter(gl.ALIASED_POINT_SIZE_RANGE)` to get max point size, clamp pointSize to [1, maxPointSize]
4. Compile particle program via `compileProgram(gl, VERT_SRC, FRAG_SRC)`
5. Compile fade program via `compileProgram(gl, FADE_VERT_SRC, FADE_FRAG_SRC)`
6. Create particle VAO via `createParticleVAO(gl, program, data.length / 4)`
7. Create fade quad VAO (3 vertices for fullscreen triangle, static buffer)
8. Upload color ramp texture via `createRampTexture(gl, getRampLUT(colorRamp))`
9. Set up context loss handler via `setupContextLossHandler(canvas, onLost, onRestored)` where onLost sets contextLostRef=true and onRestored re-creates all resources
10. Start rAF loop

**WebGL2 rAF loop:**
1. If contextLostRef.current, skip frame
2. Set viewport to canvas pixel dimensions (width * dpr, height * dpr)
3. If `trails` is true:
   - Bind fade program, set u_fadeColor to `vec4(10/255, 10/255, 15/255, trailAlpha)` (background #0a0a0f)
   - Enable blending: `gl.blendFunc(gl.SRC_ALPHA, gl.ONE_MINUS_SRC_ALPHA)`
   - Draw fade fullscreen triangle
   - For particle drawing, set blending based on `blendMode`:
     - "additive": `gl.blendFunc(gl.SRC_ALPHA, gl.ONE)`
     - "normal": `gl.blendFunc(gl.SRC_ALPHA, gl.ONE_MINUS_SRC_ALPHA)`
   - Increment frameCountRef, every 1000 frames do full clear then re-enable fade
4. If `trails` is false: `gl.clear(gl.COLOR_BUFFER_BIT)`, set blend to `gl.blendFunc(gl.SRC_ALPHA, gl.ONE_MINUS_SRC_ALPHA)`
5. Enable blending: `gl.enable(gl.BLEND)`
6. Use particle program, bind particle VAO
7. If `colorMap` is a function: iterate data, compute custom color values, write into velocity slots (vx/vy replaced with colorT, 0). Otherwise velocity-based mapping happens in shader.
8. Upload data via `gl.bufferSubData(gl.ARRAY_BUFFER, 0, data.subarray(0, count * 4))`
9. Set uniforms: u_transform (orthographic projection matrix as mat3 mapping [0,width]x[0,height] to [-1,1]x[-1,1]), u_pointSize (clamped value * dpr), u_colorRamp (texture unit 0)
10. `gl.drawArrays(gl.POINTS, 0, count)`
11. `rafRef.current = requestAnimationFrame(loop)`

**Canvas2D fallback rAF loop** (separate useEffect triggered when modeRef.current === 'canvas2d'):
1. Get `canvas.getContext('2d')`
2. If `trails`: `ctx.fillStyle = \`rgba(10, 10, 15, ${trailAlpha})\``; `ctx.fillRect(0, 0, w, h)`; set globalCompositeOperation based on blendMode ('lighter' for additive, 'source-over' for normal). Full clear every 1000 frames.
3. If no trails: `ctx.clearRect(0, 0, w, h)`
4. For each particle (i=0 to count): read x,y from data[i*4], data[i*4+1], read vx,vy from data[i*4+2], data[i*4+3]. Compute colorT (speed = Math.sqrt(vx*vx + vy*vy), clamped to [0,1]). Look up color via `colorRamps[colorRamp](colorT)`. Draw `ctx.beginPath(); ctx.arc(x*dpr, y*dpr, pointSize*dpr*0.5, 0, Math.TAU); ctx.fillStyle = color; ctx.fill();`
5. `requestAnimationFrame(loop)`

**Cleanup:** Cancel rAF, delete all GL resources (program, fadeProgram, vao, fadeVao, buffer, fadeBuffer, texture), remove context loss handlers, null out refs.

**DPR handling:** `const dpr = window.devicePixelRatio || 1;` Set `canvas.width = width * dpr; canvas.height = height * dpr;` style: `width: ${width}px; height: ${height}px`.

**JSX return:** Single `<canvas>` element with ref, className, style (width, height, background: '#0a0a0f' which is var(--sim-bg) default).

**Custom colorMap handling:** When `colorMap` is a function (not 'velocity'), before uploading to GL buffer, iterate particles and replace the velocity components in a scratch Float32Array with the custom color value. This ensures the vertex shader's `v_colorT = clamp(speed, 0.0, 1.0)` reads the custom value. Specifically: for custom colorMap, create a copy of data, then for each particle i: `copy[i*4+2] = colorMap({x: data[i*4], y: data[i*4+1], vx: data[i*4+2], vy: data[i*4+3]}); copy[i*4+3] = 0;`. Upload the copy instead. Cache the scratch array in a ref to avoid re-allocation.
