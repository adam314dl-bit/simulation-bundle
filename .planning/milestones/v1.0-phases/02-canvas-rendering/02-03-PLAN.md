**Rendering strategy (two-tier):**

1. **Full repaint (initial paint, zoom change, ramp change):**
   - Create/reuse an offscreen canvas sized to `gridW * cellSize` x `gridH * cellSize`
   - Use ImageData approach: create ImageData of grid pixel dimensions, fill pixel-by-pixel from data + LUT
   - For each cell `[row][col]`: value = `data[row * gridW + col]`, LUT index = `Math.max(0, Math.min(255, Math.round(value * 255))) * 4`, write RGBA into ImageData buffer for the cellSize x cellSize pixel block
   - `putImageData` onto offscreen canvas
   - Then `ctx.drawImage(offscreenCanvas, 0, 0)` onto main canvas (drawImage respects transforms, putImageData does not)
   - Set `prevDataRef.current = copy of data` (use Float64Array or slice to snapshot)
   - Set `needsFullRepaintRef = false`

2. **Dirty-rect update (subsequent frames):**
   - Compare `config.data` with `prevDataRef.current` element-by-element
   - Collect changed indices into a Set
   - If Set is empty, just `ctx.drawImage(offscreenCanvas, 0, 0)` (no changes)
   - If Set size > 30% of total cells, do full repaint instead (more efficient)
   - Otherwise: for each dirty index, compute col/row, look up color from LUT, `fillRect` on offscreen canvas, then `ctx.drawImage` main canvas
   - Update `prevDataRef.current`

3. **Trigger full repaint when:** scale changes (compare `viewport.scale` vs `lastScaleRef`), colorRamp changes, grid dimensions change, or data ref changes identity

**Border rendering (when borderWidth > 0):**
- After cell fills, draw borders on top (not as gaps)
- For dirty cells only: `ctx.strokeStyle = 'rgba(255,255,255,0.15)'`, `ctx.lineWidth = borderWidth`, `ctx.strokeRect(col * cellSize, row * cellSize, cellSize, cellSize)`
- Use a neutral semi-transparent color that works on any ramp

**Hover highlight:**
- Track hovered cell in `hoveredCellRef`
- After grid render, if hovered cell exists: `ctx.fillStyle = 'rgba(255,255,255,0.3)'`, `ctx.fillRect(col * cellSize, row * cellSize, cellSize, cellSize)`

**Selection highlight (highlightCell prop):**
- After grid render, if `highlightCell` exists: draw 2px solid border in `--sim-accent` color (read from `getComputedStyle` or use fallback `#6366f1`)
- `ctx.strokeStyle = accentColor`, `ctx.lineWidth = 2`, `ctx.strokeRect(col * cellSize + 1, row * cellSize + 1, cellSize - 2, cellSize - 2)` (inset by 1px for visibility)

**Hit testing for click/hover:**
- Need access to viewport for screenToWorld conversion
- Store viewport ref from onDraw callback
- On pointer events: get canvas-relative coords, apply `viewport.screenToWorld(cx, cy)` to get world coords, compute `col = Math.floor(worldX / cellSize)`, `row = Math.floor(worldY / cellSize)`
- Bounds check: `col >= 0 && col < gridW && row >= 0 && row < gridH`
- Build CellEvent: `{ col, row, value: data[row * gridW + col], worldX, worldY }`

**Performance notes:**
- Clamp cellSize to minimum 2: `const effectiveCellSize = Math.max(2, cellSize)`
- Use `| 0` for integer pixel coordinates in fillRect to avoid anti-aliasing
- Cache LUT reference — don't call getRampLUT every frame
